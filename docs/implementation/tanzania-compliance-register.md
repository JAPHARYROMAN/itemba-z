# Tanzania Mainland compliance register

This register is a delivery control, not legal or tax advice. Named Tanzanian professionals must confirm applicability, calculations, forms, certification, retention, and effective dates for every Itemba legal company before activation.

| Domain | Required release evidence |
| --- | --- |
| TRA EFD/VFD | Current taxpayer-system specification, sandbox/certification access, test receipts, signing and key custody, retry/reconciliation, cancellation/return procedure, outage procedure |
| VAT and withholding | Company registrations, effective-dated tax codes, inclusive/exclusive rounding examples, invoice/credit-note tests, tax-account mappings, filing reconciliation |
| PAYE and payroll levies | Approved effective-dated formulas, thresholds, reliefs, employer/employee treatment, filing outputs, parallel-run sign-off |
| NSSF and WCF | Employer scope, effective-dated contribution bases/rates, remittance schedules, exception handling, liability reconciliation |
| Personal data protection | Controller/processor classification, PDPC registration, DPO, data inventory, lawful basis, notices, rights process, retention, DPIA, incidents, processor agreements |
| Cross-border hosting and support | Data-flow map, destination and subprocessors, safeguards, PDPC permit/approval where applicable, encryption and key control, support-access audit |
| Financial records | Retention schedule, immutable audit, export evidence, backup/restore, legal hold, authorized disposal |
| Banking and mobile money | Approved providers, account ownership, statement/settlement formats, credentials, reconciliation, fraud and reversal handling |

Configuration cannot be activated without owner, source authority, jurisdiction, effective date, test cases, approver, and superseded-version link. Historical transactions retain their original rates and calculation snapshots.
